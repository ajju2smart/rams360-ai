# RAMS360 — LOCAL DOCKER RUN GUIDE
# All deployment is Docker-only. No Heroku. No Vercel.
# ─────────────────────────────────────────────────────

# PREREQUISITES (run once on new machine):
#   provision_host.bat  →  installs Docker Desktop + MongoDB Tools

# ─────────────────────────────────────────────────────
# ONE-CLICK START (recommended):
# ─────────────────────────────────────────────────────
#   From the Rams360_UserGuide root folder:
#   Double-click: start_rams.bat
#
#   This runs: docker-compose up -d
#   Then opens: http://localhost:3000

# ─────────────────────────────────────────────────────
# MANUAL DOCKER COMMANDS:
# ─────────────────────────────────────────────────────

# Start all services (DB + Backend + Frontend):
docker-compose up -d

# Stop all services:
docker-compose stop

# Rebuild after code changes:
docker-compose up -d --build

# View backend logs:
docker logs rams-backend -f

# View DB logs:
docker logs rams-db -f

# ─────────────────────────────────────────────────────
# SERVICE URLS (local only):
# ─────────────────────────────────────────────────────
#   Frontend:  http://localhost:3000
#   Backend:   http://localhost:8000
#   MongoDB:   mongodb://localhost:27017/rams360_local
#              (inside container: mongodb://db:27017/rams360_local)

# ─────────────────────────────────────────────────────
# DATA SYNC (one-time clone from cloud to local):
# ─────────────────────────────────────────────────────
#   Double-click: sync_data.bat
#   This clones the live DB into your local Docker container.
#   Run ONCE after first setup, or when you need fresh data.
